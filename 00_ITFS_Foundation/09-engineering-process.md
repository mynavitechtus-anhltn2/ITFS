# 09. Engineering Process

## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Git cơ bản. Conventions. Linter/formatter. Branch & PR process.

**AI Fluency:** Không commit AI output chưa qua linter. Nhận biết AI vi phạm conventions. (P10)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Hiểu conventions, clean code, git flow, code review, CI/CD pipeline.

**AI Fluency:** AI output cần CÙNG process. AI tăng velocity → risk skip review. (P6, P10)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Clean code nhất quán (DRY, meaningful names). PR description rõ, self-review. Git flow đúng chuẩn.

**AI Fluency:** Enforce process cho AI code: conventions, PR, self-review, evidence. Không fast-track. (P6, DoR/DoD)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

Không lỗi conventions. Backlog & git flow. Code review chi tiết. Task với how-to-do & evidence.

**AI Fluency:** Process compliance toàn bộ output (human+AI). DoR→implement→DoD→merge. (DoR/DoD)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** Process effectiveness. Git/backlog process cho team
- **[Expert]** Clean code multi-dimension. Code generators, custom tooling

**AI Fluency:** AI adoption thay đổi process compliance? Coach discipline. (V6)

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** Triển khai & giám sát quy trình. Kỷ luật. Activities techlead 5 phases
- **[Expert]** Process improvements best practices. Hỗ trợ PO. Quy trình công ty

**AI Fluency:** AI-specific process: mandatory review, quality gates, Context Packet. (V5)

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Process across projects. Approve changes. Drive engineering standards
- **[Expert]** Workflows & tooling. Process best practices. Engineering handbook

**AI Fluency:** Evaluate AI impact lên process compliance across teams.

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** Process standards department. Giám sát quy trình tăng hiệu quả
- **[Expert]** Engineering excellence standards. Process improvement frameworks

**AI Fluency:** Process standards AI-augmented dev — balance velocity vs discipline.

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** Engineering culture tổ chức. Process framework at scale
- **[Expert]** Sáng tạo engineering practices mới. Industry standards

**AI Fluency:** Kiến tạo AI-era process frameworks. Manifesto adoption org level.
