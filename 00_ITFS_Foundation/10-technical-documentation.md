# 10. Technical Documentation

> Vẽ rõ ràng. Viết mạch lạc. Từ ghi chép đến truyền đạt kiến trúc hệ thống.

## Lộ trình học · 9 giai đoạn

| #   | Giai đoạn                                | Nội dung & lý do quan trọng                                                                                        |
| --- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 1   | **Documentation Basics**                 | Diagrams, meeting notes, task notes, tools — why shared understanding starts with captured knowledge               |
| 2   | **Documentation Principles**             | Specs, diagram reading, accuracy, clarity — why undocumented thinking creates delivery risk                        |
| 3   | **Technical Notes & Setup Docs**         | Activity diagrams, DB diagrams, README, setup guides — why implementation needs usable documentation               |
| 4   | **Design & Decision Documentation**      | Class, component, sequence diagrams, API docs, ADRs — why complex systems need explicit decisions                  |
| 5   | **Architecture Communication**           | Architecture, infra, state machine diagrams, proposals — why good documentation aligns teams quickly               |
| 6   | **Project Documentation Architecture**   | Standards, knowledge base, review process, solution proposals — why projects need durable documentation systems    |
| 7   | **Cross-Project Knowledge Strategy**     | Writing quality, system design docs, best practices, KM — why scale requires shared language and reuse             |
| 8   | **Documentation Governance & Platforms** | Standards, tools, platforms, technical writing excellence — why departments need trusted documentation foundations |
| 9   | **Enterprise Knowledge Vision**          | Documentation frameworks, KM systems, AI-augmented workflows — why knowledge becomes an organizational capability  |

## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Nhận biết diagrams (flowchart, ER). Meeting/task notes. Tools (Confluence, Notion, draw.io).

**AI Fluency:** Dùng AI draft notes. Nhận biết AI docs có thông tin sai. (P1)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Hiểu tại sao documentation quan trọng. Giải thích diagrams. Đọc hiểu technical specs.

**AI Fluency:** Review AI docs cho accuracy — "nghe hay" nhưng có thể sai. (P3)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Vẽ Activity, Database Diagram. README, setup guides. Technical notes.

**AI Fluency:** AI draft, engineer validate mọi technical detail. Docs = actual implementation. (V1)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

Class, Component, Sequence Diagrams. Proposals. API docs. ADRs. Tài liệu đầy đủ.

**AI Fluency:** AI skeleton, engineer accurate details. ADRs = actual reasoning. (P4)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** Documentation gaps. Review quality. Consistency
- **[Expert]** Architecture, Infra, StateMachine Diagrams. Solution proposals stakeholders hiểu ngay

**AI Fluency:** AI docs thiếu gì so với experienced engineer?

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** Documentation standards. Knowledge base. Strategy
- **[Expert]** Solution proposals phức tạp cho khách. ≥4 solutions/năm

**AI Fluency:** AI docs phải accurate before publish. Define review process.

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Documentation across projects. Drive knowledge management
- **[Expert]** Technical writing quality. Best practices. Approve system design docs

**AI Fluency:** Evaluate AI documentation accuracy standards.

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** Documentation standards department. Knowledge management investments
- **[Expert]** Technical writing excellence. Tools & platforms

**AI Fluency:** Standards cho AI-assisted documentation at dept level.

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** Knowledge management strategy tổ chức
- **[Expert]** Sáng tạo documentation frameworks. KM systems

**AI Fluency:** Kiến tạo AI-augmented documentation workflows.
