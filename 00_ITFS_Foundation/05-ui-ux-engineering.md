# 05. UI/UX Engineering

> Xây giao diện chuẩn. Trải nghiệm mượt. Từ implement UI đến kiến tạo design system.

## Lộ trình học · 9 giai đoạn

| #   | Giai đoạn                              | Nội dung & lý do quan trọng                                                                                         |
| --- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 1   | **UI Foundations**                     | HTML semantics, CSS layout, UI libraries — why good interfaces start with structure and clarity                     |
| 2   | **Component Foundations**              | Components, state, responsive design, accessibility, CSR vs SSR — why UI structure shapes maintainability           |
| 3   | **UI Implementation**                  | Design specs, validation, loading, error, empty states — why real products must handle edge cases well              |
| 4   | **Feature UI Ownership**               | Reusable components, complex state, UX issues, accessibility — why scalable UI needs ownership and empathy          |
| 5   | **UI Architecture & Performance**      | Shared libraries, SSR/SSG/ISR, Core Web Vitals — why reuse and performance improve product quality                  |
| 6   | **Project Frontend Architecture**      | Conventions, design systems, tokens, cross-browser strategy — why projects need shared frontend foundations         |
| 7   | **Cross-Project Engineering Strategy** | Tech choices, design system maturity, accessibility standards — why consistency matters across products             |
| 8   | **Frontend Governance & Standards**    | Roadmaps, governance, UI/UX standards, infrastructure — why teams need standards to sustain quality                 |
| 9   | **Engineering Platform Vision**        | Component ecosystems, platform strategy, AI-augmented workflows — why frontend becomes an organizational capability |

## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Nhận biết HTML semantics, CSS box model, flexbox/grid. UI library theo docs. Implement UI từ mockup đơn giản.

**AI Fluency:** Dùng AI sinh components. Nhận biết thiếu semantic HTML/accessibility. (P1)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Hiểu component architecture, state management, responsive, accessibility, CSR vs SSR.

**AI Fluency:** Phát hiện AI component structure không hợp lý. (P3)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Implement UI từ design specs. Responsive nhất quán. Handle form validation, loading/error/empty states. Quan tâm UX edge cases.

**AI Fluency:** AI sinh nhanh, engineer validate: responsive, a11y, edge states AI bỏ sót. (P2)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

Own UI feature phức tạp. Reusable components. Accessibility đúng chuẩn. Complex state management. Chủ động flag UX issues.

**AI Fluency:** AI generate fast, engineer ensure fit with real users. Review a11y, UX, design system. (V1)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** UI codebase quality, inconsistencies. Review component architecture
- **[Expert]** Component architecture cho scale. SSR/SSG/ISR. Shared library. Core Web Vitals

**AI Fluency:** Phân tích AI UI quality patterns. Design system inconsistencies.

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** Frontend architecture toàn project. Define conventions. Tech debt reduction
- **[Expert]** Design system (tokens, primitives). Cross-browser/device strategies

**AI Fluency:** Clear design spec trước khi AI generate — garbage in, garbage out.

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Frontend architecture across projects. Approve UI tech choices. Drive standards
- **[Expert]** Design system maturity. Evaluate emerging frontend tech

**AI Fluency:** Evaluate AI UI against accessibility standards + UX best practices.

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** Frontend standards department. Infrastructure investments
- **[Expert]** Design system governance. Frontend roadmap. UI/UX best practices

**AI Fluency:** Standards cho AI-assisted UI development at department level.

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** Frontend engineering vision. Platform strategy
- **[Expert]** Sáng tạo design system & component ecosystem. Thought leadership

**AI Fluency:** Kiến tạo AI-augmented design-to-code pipelines.
