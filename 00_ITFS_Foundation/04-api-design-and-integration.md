# 04. API Design & Integration

> Thiết kế API rõ ràng. Kết nối vững. Từ consume API đến kiến tạo platform.

## Lộ trình học · 9 giai đoạn

| #   | Giai đoạn                      | Nội dung & lý do quan trọng                                                                                              |
| --- | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 1   | **API Basics**                 | HTTP methods, status codes, request/response, API clients — why reliable integration starts with correct fundamentals    |
| 2   | **API Principles**             | RESTful principles, auth, versioning, REST vs GraphQL — why conventions shape interoperability                           |
| 3   | **API Contract Design**        | Contracts, validation, errors, Swagger/OpenAPI, third-party APIs — why clarity reduces integration mistakes              |
| 4   | **Advanced API Contracts**     | Backward compatibility, OAuth2/SSO, pagination, rate limiting — why growth needs stable contracts                        |
| 5   | **API Patterns & Performance** | REST, GraphQL, gRPC, real-time APIs, performance — why API style must fit use cases                                      |
| 6   | **Project API Architecture**   | Gateways, versioning strategy, system integration, lifecycle — why projects need shared API patterns                     |
| 7   | **Integration Strategy**       | Platform fit, microservice patterns, security, reliability — why system boundaries affect scale                          |
| 8   | **API Governance & Platforms** | Standards, API-first culture, developer experience, quality gates — why organizations need consistency                   |
| 9   | **Enterprise API Strategy**    | API platforms, developer portals, integration vision, AI-augmented workflows — why APIs become organizational capability |

## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Nhận biết HTTP methods, status codes, request/response. Sử dụng Postman/Insomnia. Gọi API theo docs.

**AI Fluency:** Dùng AI sinh API calls. Nhận biết sai method/status code. (P1)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Hiểu RESTful principles, JWT/auth, REST vs GraphQL, API versioning.

**AI Fluency:** Phát hiện AI vi phạm RESTful conventions. (P3)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Thiết kế API contract và implement. Input validation, error handling. Tích hợp third-party API. API docs (Swagger/OpenAPI).

**AI Fluency:** AI sinh implementation từ contract, engineer validate business logic + edge cases. (P5)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

API contract phức tạp, backward compatible. OAuth2/SSO consumer. Response format nhất quán. Rate limiting, pagination. Coordinate contracts FE↔BE.

**AI Fluency:** AI implement từ spec, engineer own contract design + cross-team coordination. (P2, P8)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** API consistency across features. Review API design. Coordinate standards
- **[Expert]** REST vs GraphQL vs gRPC. OAuth2/SSO Server. Real-time APIs. API performance

**AI Fluency:** Phân tích AI API code consistent với existing contracts. (V3)

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** API architecture toàn project. Design guidelines. Versioning strategy
- **[Expert]** API Gateway patterns. System-to-system integration. API lifecycle

**AI Fluency:** AI tốt cho implementation, yếu cho design — define boundary.

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Đánh giá API architecture across projects. Approve integration strategies
- **[Expert]** Gateway solutions. Microservice patterns (saga, choreography). API security

**AI Fluency:** Evaluate AI integration code against production reliability.

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** API governance department. Build API-first culture
- **[Expert]** API platform architecture. Integration best practices at scale

**AI Fluency:** Quality gates cho AI integrations at department level.

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** API strategy tổ chức. Integration platform vision
- **[Expert]** Sáng tạo API platform/developer portal. Industry contribution

**AI Fluency:** Kiến tạo AI-augmented API development workflows.
