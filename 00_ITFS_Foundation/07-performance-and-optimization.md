# 07. Performance & Optimization

> Đo lường trước. Tối ưu đúng. Từ nhận biết bottleneck đến hệ thống hiệu năng cao.

## Lộ trình học · 9 giai đoạn

| #   | Giai đoạn                              | Nội dung & lý do quan trọng                                                                                             |
| --- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 1   | **Performance Basics**                 | Response time, throughput, load time, DevTools — why performance starts with visibility                                 |
| 2   | **Performance Principles**             | N+1, indexing, lazy loading, code splitting, Core Web Vitals — why bottlenecks must be measured                         |
| 3   | **Profiling & Optimization**           | Explain plans, slow queries, profiling, metrics — why evidence beats guesswork                                          |
| 4   | **Benchmarking & Caching**             | Benchmarks, Redis caching, FE+BE tuning, targets — why speed needs repeatable validation                                |
| 5   | **Deep Optimization Strategy**         | Budgets, deep profiling, cache invalidation, trade-offs — why scale needs disciplined optimization                      |

| 9   | **Enterprise Performance Vision**      | Optimization frameworks, platform vision, AI-augmented workflows — why performance becomes an organizational capability |

## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Nhận biết response time, throughput. DevTools xem load time. Nhận biết app chậm.

**AI Fluency:** Dùng AI giải thích perf issues. Nhận biết premature optimization. (P1)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Hiểu N+1, cách đo hiệu năng, indexing, lazy loading, code splitting, Core Web Vitals.

**AI Fluency:** Đánh giá AI optimization suggestions hợp lý không. (P3)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Query profiler (Explain, slow_query_log). Áp dụng indexing, lazy loading, code splitting. Đo & report metrics.

**AI Fluency:** AI suggest, engineer verify bằng profiling real data. (V1)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

Benchmark (Apache Benchmark, Lighthouse). Caching Redis. Optimize FE+BE. Deliver đạt targets.

**AI Fluency:** AI suggest caching, engineer validate against real access patterns. (P8)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** Performance across features. Set budgets. Review perf impact PRs
- **[Expert]** Benchmark scenarios (Gatling/k6). Cache invalidation. Deep profiling

**AI Fluency:** AI generic patterns vs specific bottlenecks. (P12)

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** Performance architecture toàn project. Define standards. Improvement roadmap
- **[Expert]** CDN, proxy cache. I/O bottlenecks. Caching layers. Server config

**AI Fluency:** AI suggestions phải verify trước khi apply.

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Performance across projects. Approve investments. Drive culture
- **[Expert]** Load balancing. 10k+ concurrent. Performance testing standards

**AI Fluency:** Team không blindly apply AI suggestions.

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** Performance standards department. Infrastructure investments
- **[Expert]** Performance engineering best practices. High-perf architectures

**AI Fluency:** Standards cho AI-assisted performance analysis.

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** Performance engineering culture
- **[Expert]** Sáng tạo optimization frameworks. Extreme scale

**AI Fluency:** Kiến tạo AI-augmented performance workflows.
