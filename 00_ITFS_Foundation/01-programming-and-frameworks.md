## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Viết code đúng syntax theo hướng dẫn. Nhận biết cấu trúc project và conventions. Hoàn thành task đơn giản, biết escalate.

**AI Fluency:** Dùng AI hỗ trợ coding cơ bản. Nhận biết khi AI vi phạm conventions. (P1)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Giải thích code flow, logic module, tại sao conventions quan trọng. Đọc hiểu codebase người khác. Phân biệt code "chạy được" nhưng sai approach.

**AI Fluency:** Viết prompt có context. Phát hiện AI dùng pattern/library không phù hợp. (P3)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Tự implement features với ít guidance. Áp dụng clean code nhất quán. Self-review trước khi submit. Bắt đầu cross-stack (FE↔BE).

**AI Fluency:** Dùng AI thành thạo. Cung cấp Context Packet trước khi prompt AI. Review & refactor AI output. (P2, P10)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

Own module/feature end-to-end. Thành thạo ≥1 stack, productive ở secondary. Code review peers chất lượng. Refactor có hệ thống.

**AI Fluency:** Own quality cho AI code. Đảm bảo DoR trước khi AI implement, DoD trước khi merge. (P4, P7)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** Code review chiến lược — identify patterns, coach team quality. Phân tích tradeoffs chọn tech stack
- **[Expert]** Phân tích sâu frameworks (perf, DX, ecosystem). Viết shared libraries. Master nhiều stacks

**AI Fluency:** Phân tích team AI usage patterns — phát hiện khi skip quality gates. (V1)

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** Define coding standards cho project/Line. Phân tích team capabilities, plan upskilling
- **[Expert]** Phân tích technology landscape. Go-to person cho tech decisions. Contribute internal tools

**AI Fluency:** Define AI coding guidelines: mandatory human review, Context Packet requirements. (V5)

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Đánh giá tech stack decisions across projects. Approve technical choices. Drive standardization
- **[Expert]** Đánh giá emerging frameworks. Define best practices. Technical advisor cross-projects

**AI Fluency:** Evaluate AI-augmented dev practices across projects. Drive Manifesto adoption.

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** Thiết lập technology standards cho department. Build hiring bar. Evaluate tech investments
- **[Expert]** Thiết lập coding excellence standards. Evaluate technology roadmap

**AI Fluency:** Thiết lập AI-augmented development standards cho department. (V6)

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** Tạo dựng technology vision cho tổ chức. Thiết kế technology adoption framework
- **[Expert]** Sáng tạo frameworks/tools mới. Industry best practices. Thought leadership

**AI Fluency:** Kiến tạo AI-augmented development culture cho tổ chức.
