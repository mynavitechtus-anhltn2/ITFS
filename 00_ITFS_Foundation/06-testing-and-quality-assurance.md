# 06. Testing & Quality Assurance

> Test đúng chỗ. Chất lượng đúng mức. Từ viết test đến xây dựng quality culture. ⚡ SHIFT LỚN NHẤT — P7: Test Non-Negotiable

## Ma trận năng lực · 9 cấp độ

### Junior 1

**Bloom:** REMEMBER · Ghi nhớ

**Kỹ năng**

Nhận biết các loại test, testing pyramid. Chạy test suite, đọc kết quả. Test conventions.

**AI Fluency:** Dùng AI sinh tests. Nhận biết AI chỉ test happy path. (P7)

### Junior 2

**Bloom:** UNDERSTAND · Hiểu, giải thích

**Kỹ năng**

Hiểu testing pyramid, mock/stub/spy, coverage cao ≠ quality cao.

**AI Fluency:** Đánh giá AI tests có meaningful không. Phát hiện tests "đúng syntax sai logic". (V1)

### Junior 3

**Bloom:** UNDERSTAND→APPLY · Bắt đầu áp dụng

**Kỹ năng**

Thiết kế test cases — nghĩ edge cases thay vì chỉ AI suggest. Setup test environment. Bug rate ≤1/4. Evidence đầy đủ.

**AI Fluency:** AI sinh boilerplate, engineer define scenarios + edge cases. AI bỏ sót: boundary, error paths, concurrency. (V3)

### Middle 1

**Bloom:** APPLY · Áp dụng thành thạo

**Kỹ năng**

Test strategy feature phức tạp (unit+integration+e2e). Integration tests DB/API thực. Bug rate ≤1/6. Team trust merge.

**AI Fluency:** Own quality kể cả AI code+tests. Tests cover real business scenarios? (P7, DoD)

### Middle 2 (Dual Track)

**Bloom:** APPLY→ANALYZE · Áp dụng + phân tích

**Kỹ năng**

- **[Mgmt]** Test quality (không chỉ coverage %) across team. Testing gaps. Coach meaningful testing
- **[Expert]** Test architecture, automation (Playwright/Cypress). Bug rate ≤1/8

**AI Fluency:** AI tests → coverage cao nhưng bugs lọt → root cause? (V6)

### Middle 3

**Bloom:** ANALYZE · Phân tích hệ thống

**Kỹ năng**

- **[Mgmt]** Quality metrics toàn project. Testing standards. Quality = thinking, không phải tooling
- **[Expert]** Test infrastructure. CI pipeline. Test patterns. Bug rate ≤1/10

**AI Fluency:** AI tests pass CÙNG review standards — không ngoại lệ. (P12)

### Senior 1

**Bloom:** ANALYZE→EVALUATE · Phân tích + đánh giá

**Kỹ năng**

- **[Mgmt]** Testing practices across projects. Approve strategies critical systems
- **[Expert]** Test infrastructure at scale. QA automation. Best practices

**AI Fluency:** AI-assisted testing tạo false confidence? (V1)

### Senior 2

**Bloom:** EVALUATE · Đánh giá, thiết lập chuẩn

**Kỹ năng**

- **[Mgmt]** Quality standards department. Evaluate investments. Quality culture at scale
- **[Expert]** Testing reference architectures. Quality engineering standards

**AI Fluency:** Standards cho AI-assisted QA at department level.

### Senior 3

**Bloom:** EVALUATE→CREATE · Sáng tạo hệ thống mới

**Kỹ năng**

- **[Mgmt]** Quality vision tổ chức. QA framework org level
- **[Expert]** Sáng tạo testing frameworks/tools. Industry contribution

**AI Fluency:** Kiến tạo AI-augmented quality engineering frameworks.
