# Tổng quan Skills Matrix

Skills Matrix chia lộ trình thành 3 nhóm level: Junior, Middle, Senior. Mỗi level gắn với một mức tư duy theo thang Bloom.

## Bảng level

| Nhóm   | Level      | Mức Bloom            |
| ------ | ---------- | -------------------- |
| Junior | J1, J2, J3 | Remember, Understand |
| Middle | M1, M2, M3 | Apply, Analyze       |
| Senior | S1, S2, S3 | Evaluate, Create     |

## Checklist tự đánh giá

- [x] Biết level hiện tại
- [ ] Xác định target level
- [ ] Lập planning cho từng pillar

## Lưu ý

:::tip
Một target level nên tách thành nhiều improvement goal nhỏ.
:::

:::warning
Không nhảy level khi chưa có evidence cho level hiện tại.
:::

Xem luồng tiến level tại [Level flow](./level-flow.md).
