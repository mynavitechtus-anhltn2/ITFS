# Exercise J1-06 · Clarify Drill

Theory: [j1-06-requirement-clarify.md](../../theory/j1-06-requirement-clarify.md)

| File                     | Vai trò                                     |
| ------------------------ | ------------------------------------------- |
| [before.md](./before.md) | Các brief **mơ hồ**                         |
| [index.md](./index.md)   | **Bài làm** — viết câu hỏi Clarify + hỏi ai |

## Mục tiêu

- Nhận biết requirement/mockup thiếu thông tin
- Viết **≥2–3 câu hỏi** cho mỗi brief
- Chỉ được **hỏi ai** (design / PM / lead / buddy)

## Cách làm

1. Đọc từng brief trong `before.md`.
2. Điền vào `index.md` theo template.
3. Không implement UI trong bài này — chỉ Clarify.

## Checklist

- [ ] Brief 1: ≥2 câu hỏi + “hỏi ai”
- [ ] Brief 2: ≥2 câu hỏi + “hỏi ai”
- [ ] Brief 3: ≥2 câu hỏi + “hỏi ai”
- [ ] Mỗi câu hỏi đủ hẹp để người kia trả lời được (không chỉ “làm sao?”)
